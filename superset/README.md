# Superset Profile Records

This folder stores non-sensitive Superset placement profile material for reuse and review.

## Rules

- Store only final or near-final professional content used in Superset.
- Do not store passport numbers, phone numbers, Superset IDs, addresses, screenshots, or private account details.
- Use verified profile facts from this repository.
- Keep planned, unverified, and excluded facts out of professional claims.
- Preserve project ownership boundaries, especially MITRA backend/model ownership and AEGIS architecture status.
- Do not publish private or ongoing project links unless they are already intentionally public.

## Files

- `profile-submission.md` - Superset summary text and placement-profile upload checklist.
- `certificates/INDEX.md` - curated proof-document index for Superset uploads.
- `certificates/` - selected certificate PDFs used as profile proof.
