### VisionPay

```text
Title: VisionPay
Domain: AI/ML, Computer Vision, Assistive Technology
Status: Completed
```

```text
Built VisionPay as a personal project for real-time Indian currency denomination detection with spoken feedback for visually impaired users. I collected around 400 images per denomination for INR 10, INR 20, INR 50, INR 100, INR 200 and INR 500 notes, trained a MobileNetV2-based model and converted it to TensorFlow Lite for offline CPU-oriented inference. The system uses webcam input, TTS output, confidence checks, majority smoothing, a background class and auto-count mode.

GitHub: https://github.com/MdShabazS/visionpay
```

### Automotive Body Control Module

```text
Title: Automotive Body Control Module
Domain: Embedded Systems / Automotive Electronics
Status: Completed
Associated With Display Name: Personal Embedded Project
```

```text
Built an Automotive Body Control Module prototype using ESP32. The project includes an OFF/ACC/ON ignition state machine, brake control, left and right indicators, synchronized hazard mode, buzzer feedback and an OLED dashboard. I used non-blocking millis-based scheduling, brake debouncing, GPIO abstraction and edge-triggered serial logging to make the firmware behavior more structured and reliable.

GitHub: https://github.com/MdShabazS/Automotive-Body-Control-Module-ESP32
```
