# Roadmap Analysis

This analysis is based only on the supplied Analytics with Annu brochure.

## Extracted Structure
- Program direction: AI & Data Science learning path.
- Stated path: from Python basics to deploying production AI systems.
- Phases: 6.
- Capstone project titles: 10.

## Extracted Phases
- Phase 1: Computational Foundation - Python Fundamentals, Advanced Python, SQL & Databases, Statistics & Mathematics for AI.
- Phase 2: Data Analytics Engineer - Excel for Data Analytics, NumPy & Pandas, Data Visualization, Power BI / Tableau, Exploratory Data Analysis (EDA).
- Phase 3: Machine Learning Engineer - ML Fundamentals, ML Algorithms, Feature Engineering & Optimization, Deep Learning, Deep Learning Frameworks.
- Phase 4: Generative AI & LLM Engineering - Generative AI Fundamentals, Prompt Engineering, LLM Engineering, AI Application Development.
- Phase 5: RAG, LangChain & Agentic AI - RAG Architecture, Vector Databases, LangChain Deep Dive, LangGraph, Agentic AI Engineering, MCP Protocol.
- Phase 6: Cloud, MLOps & Deployment - Cloud Computing for AI, MLOps Engineering, Backend & Deployment, Git & Version Control.

## Boundary
