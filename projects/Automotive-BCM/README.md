# Automotive Body Control Module

Automotive BCM is a personal individual embedded project. The canonical structured record is [`facts.yaml`](facts.yaml).

## Platform

ESP32.

## Core Features

- OFF / ACC / ON ignition FSM
- Brake control
- Left/right indicators
- Synchronized hazard mode
- Non-blocking millis-based scheduling
- Buzzer feedback
- OLED dashboard
- Brake debouncing
- Edge-triggered serial logging
- GPIO abstraction

## Positioning

Embedded/automotive firmware project demonstrating state-machine and real-time event-loop design.
