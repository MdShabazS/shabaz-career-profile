# Smart Wellness Desk Assistant

Smart Wellness Desk Assistant is a college team project. The canonical structured record is [`facts.yaml`](facts.yaml).

## Platform

STM32 Nucleo-L476RG.

## Shabaz's Confirmed Hands-On Contribution

- Sensor interfacing
- Testing/debugging
- Hardware wiring

## System

Presence detection, temperature monitoring, OLED feedback, break reminders, buzzer alerts, and a deterministic event/state loop using STM32 HAL.

## Known Technologies

- STM32CubeIDE
- STM32 HAL
- Ultrasonic sensing
- ADC temperature sensing
- I2C OLED
- Timers
- Embedded C
