# NexCast Pro

NexCast Pro is an internship project. Shabaz explicitly stated he did it alone. The canonical structured record is [`facts.yaml`](facts.yaml).

## Description

Intelligent floor-plan projection system that ingests floor plans, extracts useful measurements/features, divides plans into projector zones, and renders zones for multi-projector display.

## Known Stack

- Python
- Flask
- OpenCV
- Tesseract OCR
- pdf2image / Poppler
- pygame
- HTML/CSS/vanilla JavaScript
- REST APIs
- JSON configuration
- Web UI

## Known Capabilities

- PDF/image/DXF/DWG ingest
- Auto-crop
- Wall detection
- Door-related CV processing
- OCR for dimensions and room labels
- 1-12 projector zone layouts
- Per-zone display assignment
- 1920x1080 zone output
- pygame display subprocess
- Persisted configuration

Do not invent additional capabilities.
