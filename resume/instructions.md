# Resume Instructions

## Supported Modes

### Professional Resume

Use Shabaz's supplied prompt to determine target role, format, length, tone, project selection, ordering, and ATS strategy.

### Company-Specific Resume

Use the company/JD supplied by Shabaz. Map requirements to verified profile evidence and tailor accordingly.

Expected workflow:

Company/JD -> requirements -> eligibility -> selection process -> skill mapping -> gap analysis -> study plan -> coding/aptitude plan -> technical interview plan -> HR/interview plan -> tailored resume

## Hard Rules

- Never invent.
- Never mark planned certifications as completed.
- Never include excluded projects unless explicitly authorized.
- Do not overstate team ownership.
- Keep MITRA backend/model ownership separate from app ownership.
- Keep the AEGIS AI-human responsibility boundary intact.
- Prefer measurable facts only when verified.
- If a required detail is missing, omit it or mark it for verification rather than fabricating it.
- Do not lock one resume format permanently; follow the user's prompt for each resume.
