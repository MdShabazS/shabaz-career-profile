# ATS Readiness Notes

There is no universal ATS score. Results vary by platform and by the job description, so the repository does not claim that this resume guarantees a 90+ score.

The current resume is positioned for Telecom / 5G Engineer roles with a Software & Embedded Engineer headline. Assess keyword alignment against the specific job description each time.

## Current formatting goals

- Single-column, selectable text with standard section headings.
- Verified keywords only, placed in relevant skills, experience, and project context.
- Clear dates, role titles, project ownership, and study-versus-work distinctions.
- No unsupported numeric ATS score, proficiency rating, or job-match percentage.

## Historical analysis

Earlier internal score estimates and embedded/automotive role-match tables were for a previous resume direction. They are not current ATS results and must not be used as claims. Create a fresh, JD-specific analysis when a real Telecom/5G job description is supplied.
