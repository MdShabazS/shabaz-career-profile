# BITM Placement Strategy

## Primary Objective

Maximize probability of securing a strong software placement through BITM while retaining embedded opportunities.

## Core Software Preparation

- Java
- DSA
- SQL
- DBMS
- Operating Systems
- Computer Networks
- Aptitude
- Coding rounds
- Communication/interview preparation
- Git/GitHub
- Project explanation

## Parallel Embedded Preparation

Maintain:

- C/C++
- Embedded C
- microcontrollers
- embedded systems concepts
- hardware/debugging experience

## Company-Specific Workflow

For each company visiting BITM:

1. Capture company and JD information.
2. Verify eligibility.
3. Identify selection rounds.
4. Map requirements to verified skills.
5. Identify gaps.
6. Prioritize preparation.
7. Prepare technical, aptitude, HR, and interview material.
8. Tailor resume using only verified facts.

## Offer Evaluation

Use:

1. Company reputation
2. Package
3. Role
4. Growth

Evaluate lower-than-target offers case-by-case.
